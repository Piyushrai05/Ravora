# Ravora

Premium Laundry & Dry Cleaning Web Application built with React, TypeScript, Vite, and Tailwind CSS.

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```
